## Other proposal requirements
- Logo and branding manager: authorized upload/replace, default placeholder, validation, Supabase Storage, Super Admin control.
- Profiles: full name, student ID, email, academic year, photo, status, membership number.
- Files: PDF, DOC/DOCX, PPT/PPTX, XLS/XLSX, JPG/JPEG/PNG/WebP, ZIP; upload/download, metadata, search/filter, validation, moderation.
- Roles: Super Admin, Admin, Member; server-side and database/storage enforcement.
- Events: dates, venues, registration period, capacity; registrations and status.
- Notifications: in-app; email only after provider setup.
- Search/analytics: member totals/status/year distribution, events, registrations, files, outreach; no private data in public analytics.
- Architecture: Next.js/React/TypeScript, Supabase PostgreSQL/Auth/Storage, Cloudflare-compatible deployment.
- Security: RLS, server authorization, role separation, input validation, rate limiting, audit, backup/recovery, privacy/acceptable use.
- Design: blue/teal/white, responsive, bilingual, accessible, loading/success/error states.
