# Feature implementation register

The feature inventory and route map are established in this package. Some modules require provider configuration and further implementation before production acceptance.

| Area | Included foundation | Production verification needed |
|---|---|---|
| Public pages | Home and route map | Final association-approved content |
| Authentication | Supabase client setup | Auth forms, callback and recovery tests |
| Member/Admin/Super Admin | Role model and protected SQL baseline | Server actions and end-to-end role tests |
| 25 features | Coverage matrix and module requirements | Complete workflows and acceptance tests |
| Uploads/logo | Bucket plan and validation requirements | Storage policies and upload UI |
| Reports | Metrics requirements | Authorized queries and CSV export |
| Notifications/newsletter | Requirements and schema | Email provider and delivery testing |
| Backup | Recovery plan outline | Scheduled backup and restore test |
